About me

Stefanus Mario Bersyuby

I'm Stefanus, an Information Systems student. Most of what I know comes from building things I wanted to use: a Linux overlay that behaves like a Dynamic Island, a Laravel app for a final project, a Next.js site built around a design system.

I care about software that stays out of the way. That usually means fewer elements, clear type, and code I can explain. Right now I'm improving my frontend work and learning more about how systems fit together.

“Fewer elements, clearer intent.”
